---
title: "从 ReinaManager 导入数据"
description: "将 ReinaManager 的 SQLite 数据库备份迁移到 LunaBox。"
---

LunaBox 可以读取 ReinaManager 导出的 SQLite 数据库备份，并在导入前展示游戏、重复条目与本机文件状态。

## 准备数据库备份

请先在 ReinaManager 中导出数据库备份。LunaBox 接受 `.db`、`.sqlite` 和 `.sqlite3` 文件。

![alt text](/image/reina-import.png)
<Callout type="warn" title="导入前备份">

建议先在 LunaBox 的 **设置 → 数据库备份** 中创建一次备份。导入会新增游戏；选择合并时，还会更新已有条目或增加游玩记录。

</Callout>

## 执行导入

1. 打开 LunaBox 游戏库，点击 **添加游戏**。
2. 选择 **从 ReinaManager 导入**。
3. 点击 **选择数据库文件**，选中准备好的 SQLite 备份。
4. 在预览页勾选需要迁移的游戏。
5. 根据重复条目的处理需求选择一种方式，然后点击导入按钮。

| 重复条目处理 | 效果 |
| --- | --- |
| **跳过** | 保留 LunaBox 中的已有条目 |
| **仅合并** | 保留已有游戏资料，仅加入备份中的游玩记录 |
| **更新并合并** | 使用 ReinaManager 资料更新已有条目，同时加入游玩记录 |

缺少启动文件的游戏会显示 **无地址**。保留这类条目后，可以进入游戏详情重新指定启动文件。

## 可迁移的数据

导入器会读取名称、开发商、简介、评分、发行日期、封面网址、标签、完成状态、启动文件、游戏目录、存档位置、游玩记录，以及 Locale Emulator 和 Magpie 开关。封面仅接受可访问的 HTTP 或 HTTPS 网址。

ReinaManager 中的 Bangumi、VNDB、Ymgal、DLsite 与 ErogameScape 标识会转换为 LunaBox 的元数据来源。混合元数据条目会按照可用来源选出主要标识，并保留其余来源关联。

## 导入后检查

请在结果页查看成功、跳过与失败数量。随后抽查以下内容：

1. 启动文件与存档位置在本机有效。
2. 游戏状态和游玩时长符合原资料。
3. 远程封面可以正常加载。
4. 采用 **更新并合并** 的条目保留了所需的自定义内容。
