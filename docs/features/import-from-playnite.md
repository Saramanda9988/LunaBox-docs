# 从Playnite导入数据

LunaBox 支持从 [Playnite](https://playnite.link/) 导入游戏数据，方便用户快速建立游戏库。请按照以下步骤操作：

## 1. 准备工作
确保您已经在电脑上安装并使用过 Playnite，并且有可用的游戏数据。游戏均有本地启动路径

## 2. 导出 Playnite 数据

下载最新的 [Playnite 导出插件](https://github.com/Saramanda9988/LunaBox-playnite-expoter/releases/latest)

打开 Playnite，安装此插件：
1. 点击左上角的菜单按钮，选择 扩展 -> 导出到 LunaBox，将 playnite 库中的数据导出为 JSON 文件
  ![playnite.png](/image/playnite.png)

::: warning
### 注意事项
1. 此插件支持 playnite 10+ 版本，最低sdk版本为 PlayniteSDK 6.4.0 ，请注意版本
2. 在完成导入之前请不要卸载playnite，可能会破坏对应的封面数据
3. **一切出现的数据问题，作者概不负责，请谨慎操作**
:::

## 3. 导入数据
- 在游戏库页面，点击 **添加游戏** 按钮，选择 **从 Playnite 导入** 选项。
- 在弹出的文件选择对话框中，找到并选择之前导出的 Playnite JSON 数据文件。
- 系统会自动预览将要导入的游戏列表，您可以查看哪些游戏将被导入、哪些已存在、哪些没有路径。
- 您可以选择是否跳过没有路径的游戏。
- 点击 **导入** 按钮，LunaBox 会自动解析文件并导入游戏数据。

## 4. 导入选项说明
![img_4.png](/image/playnite-import.png)
- **跳过无路径的游戏**：勾选此项将跳过没有重复的游戏（可能是具有相同目录或者重复元数据信息的游戏）
- **仅合并**: 对于重复的游戏，不更新其元数据，只是将游玩记录合并进入
- **更新并合并**: 对于重复的游戏，更新其元数据，只是将游玩记录合并进入

## 5. 确认导入结果
导入完成后，您可以在游戏库中查看导入的游戏列表。系统会显示导入成功、跳过和失败的游戏数量，确保所有数据正确无误。
