# 从 Vnite 导入数据

LunaBox 支持从 Vnite 导入游戏数据，帮助您快速迁移现有游戏库与部分游玩记录。

## 1. 准备工作

请先确认您本机已有 Vnite 数据目录，并且目录中包含 Vnite 的数据库数据。推荐使用备份进行导入，以免破坏原有数据

![alt text](/image/vnite-import-1.png)

## 2. 导入数据

- 在游戏库页面，点击 **添加游戏** 按钮，选择 **从 Vnite 导入** 选项。
![alt text](/image/vnite-import-2.png)
- 在弹出的文件选择对话框中，找到并选择之前导出的 Vnite 数据库文件夹。请您提前解压
- 系统会自动预览将要导入的游戏列表，您可以查看哪些游戏将被导入、哪些已存在、哪些没有路径。
![alt text](/image/vnite-import-3.png)

::: info
#### 数据映射说明
导入 Vnite 数据时，LunaBox 会尽可能映射以下信息：
- 游戏名称（优先主名称，缺失时回退原名）
- 开发商信息
- 游戏路径（最好是文件启动配置）与存档路径（若存在）
- 数据源类型与来源 ID（如 VNDB / Ymgal / Bangumi）
- 封面图片（若 Vnite 数据中存在可读取封面）
- 游玩计时记录（可解析时会写入 LunaBox 游玩会话）
:::

::: warning
**一切出现的数据问题，作者概不负责，请谨慎操作**
:::

## 3. 确认导入结果

导入完成后，您可以在游戏库中查看导入的游戏列表。系统会显示导入成功、跳过和失败的游戏数量，确保所有数据正确无误。LunaBox 会跳过已存在的游戏，避免重复导入。
