---
title: "从 YukiHub 导入数据"
description: "从 YKBAK 备份迁移游戏资料、标签与游玩记录。"
---

LunaBox 支持读取 YukiHub 导出的 `YKBAK` 备份。该方式适合将移动设备中的游戏资料和游玩记录迁移到桌面端。

## 准备 YKBAK 文件

在 YukiHub 中创建完整备份，并将生成的 `.ykbak` 文件传输到运行 LunaBox 的设备。LunaBox 可读取普通 JSON 内容以及经过 Gzip 压缩的 YKBAK 文件。

单个备份解压后的数据上限为 64 MiB。文件内容需要保留 YukiHub 的应用标识与原始结构。

## 执行导入

1. 打开 LunaBox 游戏库，点击 **添加游戏**。
2. 选择 **从 YukiHub 导入**。
3. 点击 **选择 YKBAK 文件**。
4. 在预览页勾选需要迁移的条目。
5. 保持 **跳过无地址的游戏** 处于关闭状态，然后开始导入。

<Callout type="info" title="本机启动文件">

YukiHub 的 Android 文件位置无法用于桌面系统，因此导入后的游戏会保留为空启动文件。进入游戏详情的启动配置，即可为每个游戏指定桌面端可执行文件。

</Callout>

## 可迁移的数据

LunaBox 会迁移游戏名称、原名与别名、简介、开发商、发行日期、评分、游玩状态、标签、远程封面和游玩记录。

元数据缓存中的 VNDB、Bangumi、Ymgal 与 Hikarinagi 标识也会一并保存。YukiHub 设定的首选元数据来源会获得优先使用；该来源缺少有效标识时，LunaBox 会从其余可用来源中选取。

如果分段游玩记录的合计时长少于 YukiHub 保存的总时长，LunaBox 会补充一条汇总记录，使总游玩时长保持一致。

## 重复条目与导入结果

已有游戏会依据元数据标识或名称识别，并在预览页标记。YukiHub 条目没有桌面文件地址，因此导入器会跳过已识别的已有游戏。

导入完成后，请在结果页检查成功、跳过与失败数量，并为需要启动的游戏补充桌面端可执行文件。
