title: "功能详解"
---

LunaBox 提供了丰富的功能来增强您的视觉小说管理体验。

## 游戏管理

LunaBox 的核心是高效的游戏库管理。

- **多种导入方式**：支持[手动添加](/features/manual-add/)、批量导入文件夹，以及从 [Playnite](/features/import-from-playnite/)、[PotatoVN](/features/import-from-potatovn/)、[Vnite](/features/import-from-vnite/)、[ReinaManager](/features/import-from-reinamanager/)、[YukiHub](/features/import-from-yukihub/) 和 [Steam](/features/import-from-steam/) 迁移。
- **自定义元数据**：您可以编辑游戏的封面、标题、开发者等信息。
- **状态标记**：标记游戏的通关状态（如：未开始、进行中、已完成）。
- **丰富的搜索与筛选**：通过关键词快速查找游戏，或通过分类进行筛选。
- **更准确的进程追踪**：支持自动检测实际游玩进程，避免启动器误判（见 [自动检测游玩进程](/features/auto-detect-process/)）。
- **CLI 快捷操作**：通过命令行快速查询与启动游戏（见 [命令行工具（CLI）](/features/cli/)）。

## 跨平台启动

Windows 用户可以通过 [Steam 启动](/features/launch-with-steam/) 使用 Steam Input 手柄映射和控制器布局。macOS 与 Linux 用户可以通过 [Wine](/features/launch-with-wine/) 运行 Windows 游戏；macOS 还支持 [CrossOver](/features/launch-with-crossover/)，Linux 支持由 [Steam Proton](/features/launch-with-steam-compatibility/) 管理兼容环境。

## 游玩统计

LunaBox 提供了详尽的数据统计功能。

- **多维度视图**：支持日、周、月、年视图，全方位展示游玩趋势。
- **可视化图表**：使用直观的柱状图和折线图展示数据。
- **数据导出**：一键生成分享卡片。

## AI 分析

利用 AI 技术，LunaBox 能为您生成有趣的个性化报告。

- **风格分析**：AI 分析您偏好的游戏类型和题材。
- **习惯总结**：总结您的游玩时间段和习惯。
- **趣味点评**：生成幽默风趣的评语。
