---
title: "游戏启动"
---

LunaBox 提供启动工具、跨平台兼容环境和游玩进程检测相关设置。

## 启动方式

- [启动工具配置](/launch/launch-tools/)：配置 Locale Emulator 与 Magpie。
- [使用 Steam 启动游戏](/launch/launch-with-steam/)：使用 Steam Input 和 Steam 界面。
- [使用 Wine 启动游戏](/launch/launch-with-wine/)：在 macOS 或 Linux 运行 Windows 游戏。
- [使用 CrossOver 启动游戏](/launch/launch-with-crossover/)：在 macOS 使用 CrossOver 运行 Windows 游戏。
- [使用 Steam 兼容层启动](/launch/launch-with-steam-compatibility/)：在 Linux 使用 Proton。

## 游玩进程

[自动检测游玩进程](/launch/auto-detect-process/)可识别由启动器拉起的实际游戏进程，提升计时准确性。
