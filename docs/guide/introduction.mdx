title: "简介"
---

LunaBox 是一个轻量、快速、功能丰富的视觉小说管理与游玩统计工具。

它使用 Go 编写，界面由 [MyGo](https://github.com/egoist/mygo) 原生渲染，旨在提供流畅的用户体验和丰富的功能，帮助玩家更好地管理和享受他们的游戏库。

![img.png](/image/home4introduce.png)

## 核心特性

- **游戏分类管理**：自定义分类，灵活管理游戏库。
- **游玩时长追踪**：启动游戏自动追踪游玩时长，记录你的每一次冒险。
- **原生渲染，轻量高效**：界面直接由 GPU 绘制，不依赖 WebView，也无需携带浏览器内核，启动快、占用低。
- **多维度统计**：支持按日/周/月/年等多维度统计游玩数据，一键导出统计卡片分享保存。
- **AI 分析**：内置 AI 功能，分析游玩数据，生成个性化趣味报告。
- **便捷的数据导入**：支持从 Playnite、PotatoVN、Vnite、ReinaManager、YukiHub 和 Steam 导入数据，也支持选择文件夹批量导入游戏。
- **多渠道备份与同步**：支持本地备份，以及兼容 S3 协议的存储服务、OneDrive、WebDAV 和 Umbra 云端备份，并可在多台设备之间云同步游戏库。
- **隐私与安全**：所有敏感数据均保存在本地，保障你的隐私安全。

## 技术栈

LunaBox 使用了以下技术栈构建：

| 层级 | 技术 |
|------|------|
| **语言** | [Go 1.27](https://go.dev/) |
| **界面** | [MyGo](https://github.com/egoist/mygo) 原生 UI（Windows 上使用 Direct3D 11 渲染、DirectWrite 排版文字） |
| **数据库** | [DuckDB](https://duckdb.org/) |
| **构建工具** | MyGo CLI（`mygo dev`、`mygo build`） |
| **支持平台** | Windows、macOS、Linux |

<Callout type="info" title="关于旧版本">

v2.0.0 之前的版本基于 Wails + React 构建，从 v2.0.0 起界面改用 MyGo 原生渲染，外观与操作方式保持一致，原有数据可以直接沿用。

</Callout>
