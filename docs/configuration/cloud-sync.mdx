---
title: "云同步使用指南"
description: "在多台设备之间同步游戏库资料、记录与封面。"
---

云同步用于在多台设备之间合并 LunaBox 游戏库资料。S3、OneDrive、WebDAV 与 Umbra 均可作为同步存储。

## 云同步与云备份的区别

| 功能 | 主要用途 | 使用方式 |
| --- | --- | --- |
| 云备份 | 保存数据库压缩包与游戏存档压缩包 | 选择某个备份进行上传或恢复 |
| 云同步 | 合并游戏库中的增量变化 | 点击侧边栏云图标，或启用自动同步 |

云备份适合灾难恢复和存档版本保留；云同步适合多设备持续共享游戏资料。两项功能可以同时启用。

## 启用云同步

1. 在 **设置 → 云配置** 中开启云服务，并完成一种存储提供商的配置。
2. 使用 S3、OneDrive 或 WebDAV 时，各设备首次设置同一个备份密码。Umbra 设备则登录同一个账户。
3. 打开 **设置 → 同步与备份**。
4. 开启 **启用云同步**。
5. 点击侧边栏底部的云图标执行首次同步。

侧边栏浮层会显示准备本地资料、读取云端清单、下载数据、上传封面、上传文件和提交清单等状态，也会显示最近同步时间与错误信息。

## 自动同步

开启 **启用自动云同步** 后，LunaBox 会在应用启动时执行同步，并按照设定间隔继续执行。同步间隔最小为 15 秒，默认值为 60 秒。

多设备使用时，建议采用以下顺序：

1. 开始编辑游戏库前执行一次手动同步。
2. 在一台设备上完成资料修改或游戏记录。
3. 再次执行同步，等待状态显示成功。
4. 随后在另一台设备上同步。

该顺序可以减少多台设备同时修改相同条目时的内容覆盖。

## 同步的数据

| 会同步 | 由各设备单独设置 |
| --- | --- |
| 游戏名称、别名、开发商、简介、评分、发行日期与状态 | 游戏启动文件与安装目录 |
| 元数据来源及来源标识 | 存档文件或存档目录 |
| 分类、游戏分类关系和标签 | Steam 本机启动关联 |
| 游玩记录、进度与个人评价 | 默认启动方式及设备相关工具配置 |
| 受管理的本地封面、删除记录 | Locale Emulator、Magpie 等本机工具位置 |

兼容层配置可能包含设备相关内容。跨系统同步后，请在各设备检查 Wine、CrossOver 或 Proton 设置。

## 合并与删除

同步会比较本地与云端的更新时间，并合并双方新增或修改的数据。删除操作会记录删除标记，使其他设备能够移除对应条目。

如果同一条资料在两台设备上接近同时修改，较新的更新时间通常获得采用。首次接入已有云端资料的设备，建议先创建数据库备份，再执行同步。

## 更换提供商

更换存储提供商后，新提供商拥有独立的同步清单。完成新提供商配置后执行一次同步，即可在该提供商中创建新的游戏库资料。切换前保留一份数据库备份，有助于处理配置错误或误选账户。

<Callout type="warn" title="存储安全">

S3、OneDrive 与 WebDAV 中的同步文件包含游戏库元数据、游玩记录、进度和个人评价。请使用私有存储空间、HTTPS 连接和权限范围较小的专用凭据。

</Callout>
