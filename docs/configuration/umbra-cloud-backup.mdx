---
title: "使用 Umbra 进行云备份"
description: "授权 Umbra 账户，并备份 LunaBox 数据。"
---

Umbra 是 LunaBox 支持的账户型云存储提供商。完成浏览器授权和设备注册后，可上传数据库备份、游戏存档备份，并启用游戏库云同步。

## 授权 Umbra

1. 打开 **设置 → 云配置**。
2. 开启 **启用云服务**。
3. 将 **云存储提供商** 设为 **Umbra**。
4. 使用自建或测试服务时，先在 **高级选项** 中填写服务公开地址。
5. 点击 **授权并注册 Umbra**。
6. 在浏览器中登录 Umbra，并完成授权。
7. 返回 LunaBox，确认页面显示账户名称和存储空间。
8. 点击 **测试连接** 检查授权、设备签名与备份服务。

LunaBox 默认使用官方 Umbra 服务地址。API 与 OAuth 地址会根据所填服务地址生成。修改服务地址会清除当前页面的授权状态，需要针对新地址重新授权。

<Callout type="info" title="账户与设备">

Umbra 以授权账户区分云端数据，无需设置 LunaBox 备份密码。多台设备登录同一个 Umbra 账户，即可访问该账户下的备份和同步资料。

</Callout>

## 查看存储空间

授权卡片会显示已用容量、总容量与剩余容量。上传前可点击 **刷新** 获取最新信息。容量不足时，请先清理旧备份或调整备份保留数量。

## 上传数据库与存档

数据库备份位于 **设置 → 数据库备份**。点击 **立即备份** 后，可通过云上传图标保存到 Umbra。

游戏存档需要先在游戏编辑页设置存档位置。进入游戏的 **存档备份** 页面创建本地备份，再点击云上传图标。

在 **设置 → 同步与备份** 中可以启用以下自动任务：

1. 退出应用时备份数据库。
2. 按固定间隔或每日指定时间备份数据库。
3. 创建数据库备份后上传 Umbra。
4. 游戏退出时备份并上传存档。
5. 启动游戏前恢复较新的云端存档。

## 恢复与取消授权

数据库恢复入口位于 **设置 → 数据库备份 → 云端备份**。游戏存档恢复入口位于游戏的 **存档备份 → 云端备份**。

点击 **取消授权** 会撤销当前 Umbra 授权并清除本机凭据。再次使用时需要重新完成浏览器授权和设备注册。

<Callout type="warn" title="恢复前检查">

数据库恢复将在应用重启时生效；存档恢复会替换当前存档内容。执行恢复前请核对备份时间和对应游戏。

</Callout>
