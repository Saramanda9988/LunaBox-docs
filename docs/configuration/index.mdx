您可以在 LunaBox 的设置页面进行各项功能的配置。

## AI 配置

要使用 AI 分析功能，您需要配置相应的 AI 服务提供商。

| 配置项 | 说明 |
|--------|------|
| **AI Provider** | 选择 AI 服务提供商 (例如: deepseek, openai 等) |
| **Base URL** | API 的基础地址 (Base URL) |
| **API Key** | 您的 API 密钥 |
| **Model** | 使用的模型名称 (例如: gpt-3.5-turbo, deepseek-chat) |

## 云备份配置

LunaBox 支持 S3、OneDrive、WebDAV 与 Umbra。云存储可用于数据库备份、游戏存档备份和[游戏库云同步](/configuration/cloud-sync/)。

### S3 兼容存储

支持 AWS S3、七牛云、阿里云 OSS 等兼容 S3 协议的存储服务。

[查看详细配置指南](/configuration/s3-cloud-backup/)

| 配置项 | 说明 |
|--------|------|
| **Endpoint** | S3 服务端点地址 |
| **Region** | 区域 Region |
| **Bucket** | 存储桶名称 |
| **Access Key** | 访问密钥 (AK) |
| **Secret Key** | 秘密密钥 (SK) |

### OneDrive

LunaBox 集成了 OneDrive 备份支持。

[查看详细配置指南](/configuration/onedrive-cloud-backup/)

在设置页面点击登录 Microsoft 账号并授权，即可开启 OneDrive 云端同步。

### WebDAV

WebDAV 适用于网盘、NAS 与自建服务。需要填写服务地址和账号凭据，并为多设备设置一致的备份密码。

[查看 WebDAV 配置指南](/configuration/webdav-cloud-backup/)

### Umbra

Umbra 通过浏览器授权和设备注册连接账户，无需设置备份密码。

[查看 Umbra 配置指南](/configuration/umbra-cloud-backup/)

## 云同步

云同步会在设备间合并游戏资料、分类、标签、游玩记录、进度、评价和封面。本机启动文件、存档位置与 Steam 关联由各设备分别维护。

[查看云同步使用指南](/configuration/cloud-sync/)
