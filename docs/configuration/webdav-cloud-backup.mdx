---
title: "使用 WebDAV 进行云备份"
description: "将数据库与游戏存档备份保存到 WebDAV 服务。"
---

LunaBox 可以使用支持 WebDAV 的网盘、NAS 或自建服务保存数据库备份和游戏存档备份，同一配置也可用于游戏库云同步。

## 准备服务信息

请准备完整的 WebDAV 服务地址、用户名和密码。推荐为 LunaBox 创建独立子目录，并使用服务商提供的应用专用密码。

服务端需要支持 `PROPFIND`、`MKCOL`、`PUT`、`GET` 与 `DELETE` 方法。建议使用 HTTPS 地址。

## 配置 WebDAV

1. 打开 **设置 → 云配置**。
2. 开启 **启用云服务**。
3. 将 **云存储提供商** 设为 **WebDAV**。
4. 首次使用时设置备份密码，长度至少为 6 位。
5. 填写 WebDAV URL、用户名和密码。
6. 点击 **测试连接**，等待成功提示。

WebDAV URL 可以包含已有子目录，例如：

```text
https://cloud.example.com/remote.php/dav/files/username/LunaBoxData
```

LunaBox 会在该位置继续创建 `LunaBox/v1/<用户标识>/` 目录。URL 中请省略查询参数、片段和内嵌账号信息。

<Callout type="warn" title="备份密码">

备份密码用于生成云端用户标识，设置完成后无法修改。多台设备需要填写同一个密码，才能访问同一组 WebDAV 数据。请将密码保存在可靠的密码管理器中。

</Callout>

## 上传数据库备份

打开 **设置 → 数据库备份**，点击 **立即备份**。本地备份创建后，可以点击云上传图标将其保存到 WebDAV。

在 **设置 → 同步与备份** 中启用 **自动上传数据库备份到云端** 后，退出备份和定时备份也可自动上传。云端数据库备份数量由对应的保留数量设置控制。

## 上传游戏存档

1. 在游戏编辑页设置存档文件或存档目录。
2. 打开该游戏的 **存档备份** 页面。
3. 点击 **立即备份**。
4. 在本地备份记录右侧点击云上传图标。

在 **设置 → 同步与备份** 中，还可以启用游戏退出时备份、自动上传存档，以及启动游戏前恢复较新的云端存档。

## 恢复备份

数据库备份可在 **设置 → 数据库备份 → 云端备份** 中恢复。LunaBox 会退出，并在下一次启动时完成数据库替换。

游戏存档可在游戏的 **存档备份 → 云端备份** 中恢复。恢复前，LunaBox 会为当前存档创建一份恢复前备份。

## 常见错误

| 提示 | 检查内容 |
| --- | --- |
| 认证失败 | 核对用户名与应用专用密码 |
| HTTP 404 或 409 | 核对服务地址和父目录写入权限 |
| HTTP 405 | 服务端可能限制 `PROPFIND` 或 `MKCOL` |
| 连接超时 | 检查 HTTPS 证书、代理设置与服务器可访问性 |
